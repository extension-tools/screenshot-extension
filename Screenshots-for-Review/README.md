# Screenshots for Review

This folder is the technical archive for screenshot QA artifacts.

## Folders

- `runs/latest/`: full raw artifacts from the latest real-site QA run.
- `reports/latest.md`: latest real-site QA summary report.
- `For-Codex/incoming/`: screenshots, examples, or problem cases that Dima wants Codex to inspect.
- `For-Codex/reviewed/`: optional place for files after Codex has inspected them.

Human-review screenshots generated by Codex go to `/Users/dima/Desktop/For-Dima-from-Codex/latest/`.
That Desktop folder should contain only disputed or review-worthy cases, not raw browser profiles or full run archives.

## Flow

1. Codex writes full automated QA artifacts to `runs/latest/`.
2. Codex copies only disputed cases to `/Users/dima/Desktop/For-Dima-from-Codex/latest/`.
3. Dima puts screenshots or examples for Codex into `For-Codex/incoming/`.
4. Codex records the result in the relevant QA report or product task.

`runs/latest/` and `/Users/dima/Desktop/For-Dima-from-Codex/latest/` are generated output and can be replaced on every QA run.
